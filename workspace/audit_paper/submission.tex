\section{Abstract}
We report an adapted autoresearch run on a single NVIDIA H20 GPU for decoding-invariant
unlearning in large reasoning models. The baseline val\_risk is 0.479835 and the best
val\_risk after six experiments is 0.479835. No proposed change lowered the metric.
The run used a fixed 300-second per-experiment budget and kept only changes that
strictly lowered val\_risk. All six experiments were discarded.

\section{Method}
The agent may edit only \texttt{train.py}; \texttt{prepare.py} and the
\texttt{evaluate()} metric are frozen. The run tag is nov23 on branch
\texttt{autoresearch/nov23}. The metric is a teacher-forced leakage likelihood,
not a generative leakage rate rho\_d.
The shipped target checkpoint had a gold-answer NLL of 5.4692 on forget01, which
means it did not reproduce the fiction under any tested decoding configuration.
A LoRA memory-injection stage produced a merged base with gold-answer NLL 0.5984,
passing the Gate-0 threshold of 1.5. The frozen retain-set baseline NLL is 1.5857.
Forgetting training held out all task\_id=1 questions; evaluation uses task\_id=1
questions. The baseline run completed 32 training steps in 14.4 seconds with
peak memory 22.0 GB and cross-strategy gap gamma 0.003984.

\section{Comparison}
We do not claim improvement over any published unlearning method. STaR (AAAI 2026)
already defines a Multi-Decoding Consistency Score, so consistency as an evaluation
metric is not novel here. Our contribution claim is limited to a training-time
invariance constraint plus a concentration-bound style certificate, and the present
run provides no positive evidence for that claim.

\section{Limitations}
The primary metric is teacher-forced likelihood, not generative leakage; the two
are related but not equivalent. Retain training rows (first 64 of retain90.json)
partially overlap the 10 retain rows used by evaluate(), so utility\_drop may be
under-estimated. No independent reproduction was performed. No cross-model
reviewer was available. The provenance link between run.log and each commit was
not verified. Generative Gate-0 failed and is replaced by a likelihood Gate-0;
conclusions about generative leakage are therefore out of scope.
