## 复核结论

1. **H1 / H4 方向复现**：完整实体泄漏 0.65→0.25→0.00；
   中等强度 α=5 时部分名绕过率从 0.05 跃升到 0.3333，
   强屏蔽 α=20 把它压回 0.0833。绕过相变不是评测集特性。
2. **但强屏蔽不是「彻底解决」**：held-out 上仍有 8.3% 的部分名绕过，
   而主循环评测里是 0.0000。不得写成「100% 无泄漏」。
3. **C2 护栏在独立样本上未通过**：主循环 retain 下降 0.0166（≤0.10，通过），
   held-out 下降 0.1174（>0.10，失败）。10 条 retain 样本功效不足，
   效用结论应标为 **样本敏感 / 未确证**。
4. **绝对值对样本敏感**：baseline worst_leak 0.95（主）vs 0.65（held-out），
   retain_rouge 0.2591 vs 0.5666。跨样本不能只报一个数字。
5. **γ 始终很小**（0–0.05）：在这个可控基座上，解码策略间的不一致性依然不显著，
   与上一轮训练期实验的 γ≈0.004 一致。H3 未获支持。
6. **Oracle 设定限制**：屏蔽用的 473 个 token id 来自 forget01 全部 400 条的实体名，
   即干预「已知要忘什么」。本实验**不包含敏感内容自动发现**（SEGUE/STaR 的探针部分），
   不能宣称端到端部署可用。

## 判定

- C1（有效性）: **PASS（方向稳定）**
- C2（效用护栏）: **主循环 PASS / held-out FAIL → 整体 NOT CONFIRMED**
- C3（一致性不放大）: **PASS（γ 始终 ≤0.05）**
- C4（诚实报告绕过）: **PASS，且是本轮最有价值的发现**

结论限定为 pilot；无跨模型评审、无 seed 重复、单基座、单 split。
